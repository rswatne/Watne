Personvernerklæring

Her forklarer vi hvilke opplysninger som behandles når du bruker watne.app, og hvordan annonser fungerer. Sist oppdatert 27. oktober 2026.

Behandlingsansvarlig

Roy Watne er ansvarlig for siden watne.app. Du når oss på rstlund@gmail.com.

Data du legger inn i verktøyene

Beregningene skjer i din egen nettleser. Verdiene du fyller inn, og innstillinger som tema, lønnsinnstillinger og privatøkonomitall, lagres lokalt i nettleseren din (localStorage) slik at du slipper å fylle dem inn på nytt. Disse dataene sendes ikke til oss eller til noen server. Du kan slette dem når som helst ved å tømme nettleserens lagrede data for siden.

Annonser og informasjonskapsler

Siden kan vise annonser fra Google AdSense. Google og samarbeidspartnere kan bruke informasjonskapsler og lignende teknologi for å vise annonser, måle visninger og forhindre misbruk. Det kan omfatte tilpassede annonser basert på tidligere besøk på nettsteder.

Du kan styre annonsetilpasning i Googles annonseinnstillinger. Du kan lese mer om hvordan Google bruker data på policies.google.com. Du kan også slette eller blokkere informasjonskapsler i nettleserinnstillingene.

Tredjepartstjenester

  • Google Fonts: Skrifttyper lastes fra Google. Da mottar Google IP-adressen din.
  • unpkg: Ikonbiblioteket Lucide lastes fra unpkg.com.
  • Cloudflare og GitHub Pages: Siden leveres via Cloudflare og hostes på GitHub Pages. De kan lagre tekniske serverlogger, som IP-adresse, tidspunkt og nettleserinformasjon, for drift og sikkerhet.

Siden bruker ikke egne analyse- eller sporingsverktøy.

Dine rettigheter

Etter personvernforordningen (GDPR) har du rett til innsyn, retting og sletting av personopplysninger vi eventuelt har om deg, og rett til å protestere mot behandling. Kontakt oss på rstlund@gmail.com. Du kan også klage til Datatilsynet.

Endringer
